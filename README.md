# WhereKnow – Android Location Finder

WhereKnow is a native Android application that helps users save, organize, and revisit important locations. The app allows users to view their current location, save custom places, and access location-based information using Google Maps services.

## Features

* View current location on a map
* Save and name important locations
* Search for nearby places such as restaurants and gas stations
* Display place information such as name, address, coordinates, rating, and type
* Calculate distance between locations
* Sort nearby places from closest to farthest
* User-friendly mobile interface

## Technologies Used

* Kotlin
* Android Studio
* Android SDK
* XML Layouts
* Google Maps API
* Google Places API
* Geolocation Services
* Git and GitHub

## Project Overview

WhereKnow was designed to help users remember and organize meaningful locations. Many people use maps daily, but they may not have a simple way to save specific places with custom names and return to them later.

This app provides a practical way to store important places, find nearby locations, and support navigation-related tasks through location-based services.
